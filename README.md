# scoop-dex

[Scoop](https://scoop.sh) bucket for [Dex](https://github.com/Hanishchow/Dex), a black-and-white gothic desktop music player built on Mornye (LGPL-3.0).

```powershell
scoop bucket add dex https://github.com/Hanishchow/scoop-dex
scoop install dex/dex
```

Update with `scoop update dex`. Windows x64 only. The app is not code-signed, so Windows may show an unknown-publisher warning the first time it runs.
